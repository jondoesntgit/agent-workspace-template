# standards/

Shared team rules, copied into every workspace by the template and refreshed by
`copier update`. **Don't edit here.** Change them in the template repo so every
project picks up the change.

- `plotting.md`: plotting conventions, typography, reproducibility rule
- `writing.md`: prose conventions
- `teamplot/`: matplotlib helpers + `matplotlibrc` (the enforcement)
- `latex/teamtufte.sty`: Tufte layout, Pagella 12 pt body, Nimbus Sans captions
- `latex/layout.tex`: page/column widths, read by both LaTeX and `teamplot`
